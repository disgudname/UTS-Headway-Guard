Kiosk Fleet

Registry of Raspberry Pi arrivals-display kiosks (chilipie-kiosk-modern image). Each kiosk checks in every ~15s via POST /v1/kiosk-checkin with its WiFi MAC address and gets told which site code to display. Assign or change the site code below to reassign a kiosk to a different bus stop — no SD card edit or redeploy needed, the kiosk picks it up on its next check-in. A device that hasn't checked in for over an hour is flagged as stale below.

For a kiosk that isn't at a bus stop at all (e.g. one displaying a spreadsheet in an office), set a URL override instead. When a URL is set, the kiosk loads it directly and ignores the site code entirely — the site code field is greyed out below to make that precedence clear.
